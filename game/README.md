# Земли Приключений

Простая приключенческая игра с видом от 3-го лица (Three.js, один HTML-файл).

## Запуск
Открой `game/index.html` в браузере (Chrome / Edge / Firefox). Нужен интернет — библиотека Three.js грузится с CDN.

## Управление
- **WASD / стрелки** — ходьба, **Shift** — бег, **Пробел** — прыжок
- **Мышь** — поворот камеры (клик захватывает курсор), **колесо** — приближение
- **E** — действие (войти / выйти из подземелья, открыть сундук)

## Что есть
- Процедурный рельеф 600×600: поляна с костром, холмы, озёра, кольцо гор и северный горный массив со снежными вершинами
- ~1700 деревьев (ели и лиственные), камни, трава; столкновения с деревьями и крутыми склонами
- Два подземелья (входы отмечены красным на миникарте):
  - **Древний склеп** — кирпичные залы, колонны, факелы, кости
  - **Пещера кристаллов** — каменные своды, светящиеся кристаллы
- В каждом подземелье — сундук с сокровищем
- Миникарта для долины и подземелий

Карты подземелий задаются ASCII-схемой в `DUNGEON_DEFS` (`#` стена, `S` вход, `C` сундук, `T` факел, `P` колонна, `K` кристалл, `B` кости) — их легко менять и добавлять новые.
