# Alex — голосовой ассистент для Android

Android-приложение голосового ассистента на Kotlin. Пришло на смену
Windows-лаунчеру `Alex.vbs`, который запускал десктопный JARVIS.

В отличие от исходного JARVIS, приложение **не тянет тяжёлые ML-модели**
(Hugging Face, Coqui TTS). Оно использует встроенные в Android сервисы:

- **`SpeechRecognizer`** — распознавание речи (STT), русский язык;
- **`TextToSpeech`** — озвучка ответов (TTS), русский язык.

## Что умеет

Нажми «🎤 Говорить» и скажи фразу. Ассистент понимает, например:

- «Привет» / «Как дела»
- «Который час» / «Сколько времени»
- «Какое сегодня число» / «Какая дата»
- «Как тебя зовут»
- «Спасибо», «Пока»

Остальные фразы он повторит и скажет, что пока не знает такой команды.
Новые команды добавляются в `handleCommand(...)` в
[`MainActivity.kt`](app/src/main/java/com/alex/assistant/MainActivity.kt).

## Сборка

### В Android Studio (проще всего)
1. Открыть папку проекта в Android Studio (Hedgehog или новее).
2. Дождаться синхронизации Gradle.
3. Запустить на телефоне или эмуляторе (Android 7.0 / API 24 и выше).

### Из командной строки
Нужны JDK 17 и Android SDK. Если в репозитории нет Gradle Wrapper,
сгенерируйте его один раз установленным Gradle 8.9:

```bash
gradle wrapper
./gradlew assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/`.

## Разрешения

- `RECORD_AUDIO` — микрофон для распознавания речи (запрашивается при первом нажатии).
- `INTERNET` — часть движков распознавания работают через сеть.

## Примечания

- Распознавание и озвучка зависят от сервисов устройства (обычно Google).
  Если русская озвучка не установлена, приложение откатится на язык по умолчанию.
- Минимальная версия Android — 7.0 (API 24), целевая — 14 (API 34).
